# Compare orchestration patterns

Five scripts demonstrate coordinator/consultation, sequence, parallel reads, review loops and a workflow graph. Start with the [router walkthrough](../walkthrough.ipynb), then inspect one script and run it from the repository root with `uv run python <path>`. These examples invoke the model and configured store services. `uv run python quickstarts/10-multi-agent-router/patterns/01_coordinator_vs_single_turn.py` runs all five.
