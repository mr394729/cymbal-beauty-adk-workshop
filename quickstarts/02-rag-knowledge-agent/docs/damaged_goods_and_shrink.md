# SOP 02 — Damaged goods and shrink logging

Cymbal Beauty operating reference. Version 2026-09-21. This is fictional retailer training source material.
General procedures do not replace a store-specific directive, stored task deadline or recorded completion criteria.


- Log every damaged, missing or suspicious unit in the shrink log within the same shift. One entry per product with:
  product id, quantity, event type (`damage`, `unknown_loss`, `return_anomaly` or `adjustment`), location in the
  store (for example "skincare aisle" or "backroom") and a one-line note describing what happened.
- Notes describe the event, never a person: write "bottle dropped during restock", not who dropped it. Do not
  include guest or associate names, phone numbers or emails.
- Damaged units go into the damage bin in the backroom and are kept for 7 days for vendor credit. Photograph any
  damaged item worth more than 50 dollars before it goes in the bin.
- A `return_anomaly` is a return that does not match the receipt (different batch code, empty box, opened seal on an
  unopened-return). Accept or refuse the return by the returns policy, then log the anomaly.
- Three or more events for the same product in 7 days: the manager reviews the pattern the next business day and
  decides whether to investigate or add prevention (locked case, peg lock, placement change).
