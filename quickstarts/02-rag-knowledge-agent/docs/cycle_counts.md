# SOP 05 — Cycle counts

Cymbal Beauty operating reference. Version 2026-09-21. This is fictional retailer training source material.
General procedures do not replace a store-specific directive, stored task deadline or recorded completion criteria.


- Each store counts one scheduled category every day, finished before 10:00, before the traffic peak.
- Count the shelf and the backroom for every product in the category and compare with the system on-hand quantity.
- Recount any product whose variance is more than 2 units or more than 100 dollars. A recount is done by a
  different associate than the first count.
- Do not cycle count a fixture that is being reset (SOP 03); count it the next day.
- On-shelf availability exception: when the system shows units on hand but nothing is on the shelf and nothing is in
  the backroom, cycle count that product the same day instead of waiting for its category.
- Post the corrected count before the end of the shift; corrections of more than 10 units need the manager's approval.
